# stash
Stash takes the web’s endless discovery and turns it into a personal visual library, converting links into curated cards with custom titles and colors. It supports contextual annotations. It works completely offline to ensure data sovereignty and guarantees seamless portability. A chill, professional way to organize your digital footprint.
